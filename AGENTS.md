# Gyan Prapti Academy (GPA) - Web Platform

This is a modern Vite + React 19 + TypeScript + Tailwind CSS v4 Single Page Application (SPA).

- **Framework**: Vite 6 + React 19 + React Router DOM
- **Styling**: Tailwind CSS v4 via `@tailwindcss/vite`
- **3D Graphics**: Three.js + `@react-three/fiber` + `@react-three/drei`
- **Icons**: Lucide React
- **Entry Points**: `index.html`, `src/main.tsx`, `src/App.tsx`
- **Routing**: Client-side routing in `src/App.tsx` using `react-router-dom`
